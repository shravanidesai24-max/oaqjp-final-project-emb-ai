# Final Project

## Emotion Detector

This repository contains the final project for the IBM Skills Network course.

The project uses Natural Language Processing (NLP) to analyze text and identify emotions expressed in the text.

The application detects the following five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion expressed in the input text.

## Technologies Used

- Python
- Watson NLP Emotion Prediction service
- Flask
- Requests
- Unit Testing
- Pylint

## Project Features

- Emotion detection from text input
- Identification of five emotions
- Detection of the dominant emotion
